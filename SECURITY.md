# Security policy

Do not publish recovery keys, passwords, real transactions, or exploit details in public issues. Use GitHub's private vulnerability reporting option if it is available on this repository. If it is unavailable, open an issue requesting a private contact without disclosing sensitive details.

This project has no independent penetration-test certification or guaranteed response SLA. A passing test suite does not establish that the app is unhackable.

See [security architecture and deployment](docs/SECURITY.md) for controls, boundaries, and outstanding production setup.
